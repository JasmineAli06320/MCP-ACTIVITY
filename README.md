# MCP-Activity

A new MCP project.

This project is my MCP Activity, where I set up a Node.js server (index.js) that Claude Desktop connects to. The server supports listing, reading, writing, and moving files inside the project folder. I used it to demonstrate the MCP workflow (M1–M5): listing files, creating and editing a file, reading its contents, simulating deletion by moving it into a trash folder, and confirming cleanup. Although the folder originally contained Flutter starter files from another repo, the focus here is on the MCP server and how it enables Claude Desktop to perform real file operations.
